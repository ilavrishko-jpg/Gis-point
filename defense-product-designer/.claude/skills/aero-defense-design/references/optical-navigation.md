# Оптична навігація: як правильно «посадити» камеру в аеро-модуль

Оптична навігація (VPS, visual odometry, terrain/feature matching, map-matching по ортофото,
star-tracker-подібні рішення) вимагає: **стабільне чисте поле зору + жорстка геометрія
камера↔IMU + передбачувана експозиція + відсутність артефактів вікна.**

## 1. Напрям і розміщення камери
| Задача | Напрям | Примітки |
|---|---|---|
| Map-matching по ортофото / VPS | надир (вниз) ±5° | мін. перспективні спотворення; середня частина фюзеляжу/поду |
| Visual odometry на малих висотах | надир або вперед-вниз 30–60° | більше текстури, але більше паралакс/горизонт |
| Терейн/горизонт, посадка | вперед-вниз 10–30° | ризик засвітки сонцем, потрібна бленда |
| Зоряна корекція | вгору/зеніт | окремий модуль, бленда з ідеально чорним покриттям |

Правила розміщення:
- **Близько до центру мас/IMU** — менше лінійних прискорень і пружних деформацій між ними.
- **Не в струмені/тіні**: вихлоп (тепловий міраж знижує MTF), гвинт (бруд/краплі/вібрація),
  зливи палива і масла, протиобмерзальна рідина, викиди гільз/контейнерів.
- **FOV вільний** у всіх конфігураціях: шасі випущене/прибране, закрилки, антени, пілони,
  кріплення поду, підвісні вантажі. Перевіряй при куті крену ±30° і тангажу крейсер/посадка.
- **Вікно в зоні прикріпленого потоку** (на циліндрі або в першій половині хвостовика при куті ≤ 8°).

## 2. Розмір вікна — рахуй
Мінімальний розмір плоского вікна (по одній осі):
`W = D_ап + 2·d·tan(FOV/2 + margin) + 2·рамка`
- D_ап — діаметр зіниці входу/передньої лінзи, d — відстань від зіниці до вікна,
  margin — 3–5° на допуски і віньєтування, рамка — 3–6 мм під ущільнення.
- Ставь об'єктив **якомога ближче** до вікна (d мінімальна) — вікно менше, дешевше, менший опір.
- Прямокутна матриця 4:3/16:9 → прямокутне вікно або «стадіон», не надлишкове коло.
- Скрипт: `aero_optics_calc.py window`.

## 3. Плоске вікно vs купол
| | Плоске | Концентричний купол |
|---|---|---|
| Оптика | без оптичної сили; у колімованому ходу лише зсув; при куті падіння > 40–50° — ріст відбиття, астигматизм у збіжному пучку | без сили, якщо центр кривизни = зіниця входу; інакше дефокус/кома |
| Аеро | заподлицо на циліндрі — добре; на носі — погано (тупий торець) | ідеально на носі/знизу, якщо кулястий сектор плавно переходить в обшивку |
| FOV | до ~90–100° практично | до ~180° (гімбал) |
| Ціна | низька | висока (особливо сапфір/ZnS) |
| Рекомендація | **за замовчуванням для надир-камер** | для гімбалів і широкого огляду вперед |

- Плоске вікно нахиляй на 2–5° відносно оптичної осі, щоб відбиття (ghost, у ІЧ — нарцисизм) не поверталось у матрицю, якщо геометрія дозволяє.
- Конформне (вигнуте за формою поду) несферичне вікно — потребує корекції в оптиці/калібровці; тільки разом з оптиком.

## 4. Матеріали вікна за спектром
| Спектр | Матеріали | Коментар |
|---|---|---|
| VIS 0.4–0.7 мкм | N-BK7, B270, плавлений кварц, **сапфір**, хім. загартоване скло (Gorilla/Dragontrail) | сапфір — найстійкіший до піску/дощу (9 Мооса); двопроменезаломлення — орієнтуй c-вісь по оптичній осі для критичної оптики |
| NIR/SWIR 0.7–2.5 мкм | плавлений кварц (IR-grade), сапфір | звичайне скло добре до ~2 мкм, перевір пропускання |
| MWIR 3–5 мкм | сапфір (до ~5 мкм, різкий спад), Si, ZnS, ZnSe, CaF₂ (крихкий, гігроскопічний) | для зовнішнього вікна — сапфір або ZnS |
| LWIR 8–12 мкм | Ge (+DLC), ZnS (FLIR-grade), ZnSe, халькогеніди | Ge темніє при > ~100 °C (тепловий розгін) — врахуй на сонці; DLC обов'язково для ерозії |
| Мультиспектр VIS–LWIR | ZnS multispectral (Cleartran), ZnSe | м'які — потрібне захисне покриття |

## 5. Покриття та функції вікна
- **AR** під робочий діапазон і кут падіння (на обидві поверхні; зовнішня — hard-coat).
- **Гідрофобне/олеофобне** зовні — краплі скочуються потоком.
- **Обігрів**: ITO (прозорий провідний, ~5–20 Ом/кв) або тонка дротова сітка (≤ 2–5 % затінення, падає MTF/дифракційні піки) — проти обмерзання і запотівання.
- **ЕМС**: та сама сітка/ITO як екран за MIL-STD-461G, заземлена по периметру через провідну прокладку.
- **Внутрішня поверхня** — AR, ніякого покриття, що розсіює.

## 6. Герметизація, запотівання, тиск
- Внутрішній об'єм осушений: продувка сухим N₂ + **дихальний клапан з мембраною ePTFE (Gore-vent)** для вирівнювання тиску при наборі висоти, + силікагель/молекулярне сито.
- Ущільнення вікна: O-ring/плоска прокладка (силікон, фторсилікон для пального), рамка-притиск, без точкових навантажень на скло; компенсація різниці ТКЛР (сапфір ~5–6·10⁻⁶/K, алюміній ~23·10⁻⁶/K) м'яким шаром (RTV).
- Аеро- і тискові навантаження: товщина — `aero_optics_calc.py thickness` (SF ≥ 4 для крихких матеріалів).

## 7. Вібрації та жорсткість (критично для навігації)
- **Камера + IMU — на одній жорсткій оптичній плиті** (Al 6061/7075-T6, Ti, CFRP з закладними); перша власна частота плити ≥ 2× від частоти збурення (типово > 300–500 Гц).
- Віброізоляція (дротяні тросові/еластомерні ізолятори) — **всього оптичного блоку** відносно корпусу; резонанс ізоляції нижче основних збурень (гвинт N/rev, двигун), але не в смузі динаміки руху, яку має бачити IMU (зазвичай 10–30 Гц зріз).
- **Вікно кріпиться до корпусу, не до плити** → між ними мінімальний зазор, вікно не має торкатися об'єктива при ходах ізоляторів (± хід ізолятора + 2 мм).
- Global shutter обов'язково (rolling shutter «желе» на вібраціях і поворотах).
- Термостабільність: різний ТКЛР дає дрейф boresight — симетричні кріплення, кінематичні опори (3 точки), штифти для повторюваного монтажу.

## 8. Експозиція, змаз, засвітка
- GSD = H · p / f (H — висота, p — піксель, f — фокусна). Змаз = V·t_exp / GSD → тримати **≤ 0.3–0.5 px**.
- Частота кадрів для VO: fps ≥ V / (L_кадру·(1 − overlap)); overlap 60–80 %.
- Засвітка: внутрішня бленда/бафли, чорне анодування (або Acktar/Vantablack-подібні покриття для critical), матові внутрішні стінки, жодних блискучих гвинтів у полі зору.
- Сонце в кадрі при вперед-вниз — передбач HDR/автоекспозицію і геометричне затінення.

## 9. Калібрування та сервіс
- Інтрінсики калібрувати **крізь вікно** (вікно — частина оптичної системи).
- Екстрінсики камера↔IMU (Kalibr-подібно) після остаточної збірки; механіка має зберігати їх при знятті/встановленні модуля (штифти, кінематика).
- Вікно — змінне з лінійки (без розбирання оптичного блоку), з доступом для чистки; маркування «CLEAN WITH IPA ONLY / NO ABRASIVES».
- Внутрішній температурний датчик і контроль обігріву — у телеметрію.

## 10. Типові значення за замовчуванням (якщо користувач не дав)
- Матриця 1/1.8"–2/3" global shutter, піксель 3.45 мкм, 2448×2048, VIS.
- Об'єктив f = 8–16 мм, FOV 40–70°, D_ап 8–15 мм, d до вікна 5–15 мм.
- Висота 300–3000 м, швидкість 80–250 км/год (БПЛА) / 200–450 км/год (пілотовані).
- Вікно: плоский сапфір 2–4 мм з AR + hydrophobic, нахил 3°, обігрів ITO.
