# Інтеграція, кріплення, стандарти, випробування

Правило: **не заявляй відповідність стандарту — пиши, за яким стандартом проектувати і що випробувати.**
Номери редакцій перевіряй на момент проекту.

## 1. Кріплення
| Носій / місце | Типове рішення |
|---|---|
| Бойові/військові ЛА, підкрильні точки | вушка 14" (≈ 356 мм) для ≤ ~1000 lb та 30" (≈ 762 мм) для важчих — MIL-STD-8591 / STANAG 3726; навантаження та фіксатори (sway braces) — за MIL-STD-8591, MIL-HDBK-1791 |
| Пілотовані цивільні (Cessna, DA42, King Air, PC-12) | сертифіковані монтажі: step-mount, belly pod на штатних точках, кронштейн на двері; модифікація = STC (EASA Part-21 / FAA) |
| Літакові БПЛА (5–200 кг) | швидкознімна планка (dovetail / Picatinny-подібна 1913 для легких), 2–4 гвинти M5–M8 з вставками у силовий шпангоут, штифти для повторюваності |
| Мультиротори | рамний монтаж на штанги (carbon tube clamps Ø16–30 мм), швидкознімний з фіксатором, віброізоляція |
| Гелікоптери | штатні hard points/кронштейни (наприклад, для FLIR-турелей), STC |
| Конформно на обшивці | клейово-гвинтове на дублер (doubler) із розподілом навантаження; оцінка втомної міцності обшивки |

Обов'язково для кріплення:
- Розрахункові перевантаження: n_z з ВЛЕ носія × коеф. безпеки 1.5; аварійні (crash) — 9g вперед для цивільних (CS-23.561 як орієнтир).
- **Подвійна фіксація** (safety wire / самоконтрящі гайки / вторинний фіксатор) — модуль не може відпасти.
- Повторюваність установки ≤ 0.05–0.1° (для збереження boresight) — штифти/кінематичні опори.
- Масово-центрувальний вплив на ЛА: зміна ЦМ в межах обмежень носія.

| 501.7 / 502.7 | висока / низька температура | −40…+71 °C типово, вікно без тріщин |
| 503.7 | термоудар | вікно/рамка, ТКЛР |
| 505.7 | сонячне випромінювання | нагрів Ge/корпусу, деградація фарби |
| 506.6 / 507.6 | дощ / вологість | IP, запотівання |
| 509.7 | сольовий туман | корозія, гальванічні пари (Al↔CFRP — ізоляція склотканиною) |
| 510.7 | пісок і пил | ерозія вікна |
| 514.8 | вібрація | профіль носія (гвинтовий / реактивний / гелікоптер) |

Цивільні ЛА — RTCA **DO-160G** (аналогічні розділи + розділ 20/21 ЕМС, 22 блискавка непрямий вплив).

## 3. Електрика та ЕМС
- ЕМС: **MIL-STD-461G** (CE102, RE102, RS103 обов'язкові мінімум) / DO-160G розд. 20–21.
- Живлення від ЛА: **MIL-STD-704F** (28 V DC), для БПЛА — фактичні шини носія з запасом на просідання.
- Блискавка: MIL-STD-464C / DO-160G розд. 22–23 для модулів на зовнішній поверхні; металізація CFRP (Cu-сітка) і струмовідвід.
- Роз'єми: **MIL-DTL-38999 Series III** (кругові, байонет/різьба, стійкі до вібрації) або MIL-DTL-26482 / D38999-сумісні легкі; для БПЛА — LEMO/ODU/Fischer IP68. Роз'єм — у задній частині або зверху, захищений від потоку.
- Інтерфейс до сховища на військових ЛА — MIL-STD-1760 (якщо под використовує штатну шину), дані — Ethernet / MIL-STD-1553 / ARINC 429 / CAN.

## 4. Герметичність, людський фактор
- IP67/IP68 за IEC 60529 (для БПЛА), або за методами 810H.
- **MIL-STD-1472H**: ручки, маса для одного техніка ≤ ~20 кг (підйом двома руками), доступ до замків в рукавицях, кольорове маркування.
- Технічне обслуговування без спецінструменту: ¼-turn фіксатори (Camloc/DZUS), захоплені (captive) гвинти — нічого не губиться на аеродромі (FOD).

## 5. Авіаційна придатність / сертифікація
- Військові: MIL-HDBK-516C (критерії льотної придатності), для БПЛА — STANAG 4671 (fixed-wing UAS) / 4703 (легкі).
- Цивільні: EASA CS-23/CS-25 + Part-21 STC, FAA AC 23-xx; зовнішні модифікації — аналіз флаттеру, вібрацій, впливу на характеристики, ППД.
- Програмне забезпечення навігації, якщо впливає на безпеку — DO-178C (цивільні) — поза межами цього скіла, але згадай.

## 6. Технологічність (DFM)
- Корпус з композиту: розʼємна оснастка по лінії, яка йде вздовж потоку; ухили ≥ 1–2°; мінімальні радіуси R ≥ 2× товщини ламінату.
- Фрезерований: уникати глибоких кишень > 4× ширини фрези, внутрішні радіуси під стандартну фрезу.
- 3D-друк (прототипи): PA12 SLS з просоченням/фарбуванням; ULTEM 9085 для авіаційно-допустимих.
- Допуски: аеро-поверхні ±0.2 мм, посадка вікна ±0.05 мм, плита камери/IMU — площинність ≤ 0.02 мм.
- Вузли: кількість унікальних кріплень ≤ 2 типорозміри.

## 7. План випробувань (мінімум, пропонуй користувачу)
1. Макет 1:1 (друк) на ЛА — перевірка кліренсу, FOV, доступу.
2. Наземний вібротест модуля (sweep 5–2000 Гц, резонанси плити).
3. Термокамера −40/+71 °C з роботою обігріву, перевірка запотівання.
4. IP-тест, сольовий туман (за потреби).
5. Льотний тест: тафти, акселерометри на плиті камери, якість кадру (MTF/різкість, змаз), дрейф калібрування до/після.
6. ЕМС-сканування поряд із радіостанціями ЛА.
