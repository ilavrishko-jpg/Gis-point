# Рубрика оцінки дизайну аеро-модуля (1–5 за віссю)

Оцінюй «до» і «після». Ціль для передачі в роботу: **жодної осі нижче 3, безпека й оптика ≥ 4.**

## 1. Безпека носія (вага ×2)
- [ ] Модуль не може відокремитися (подвійна фіксація).
- [ ] Не впливає на ППД/статичні порти, антени, повітрозабірники, керування.
- [ ] Кліренс при зльоті/посадці, кут tail-strike, випущене шасі.
- [ ] Зміна ЦМ і маса в межах носія.
5 = все перевірено з цифрами · 3 = ризики названі, план перевірки є · 1 = очевидна небезпека.

## 2. Оптика і навігація (вага ×2)
- [ ] FOV + 3–5° запасу вільний у всіх конфігураціях і при крені ±30°.
- [ ] Вікно заподлицо, у прикріпленому потоці, не в струмені/вихлопі/тіні бруду.
- [ ] Тип вікна відповідає задачі (плоске / концентричний купол), матеріал під спектр.
- [ ] Камера + IMU на одній жорсткій плиті, ізоляція всього блоку.
- [ ] Обігрів/антизапотівання/вентиляція; змінність вікна; калібрування крізь вікно.
- [ ] GSD і змаз ≤ 0.5 px пораховані.

## 3. Аеродинаміка
- [ ] L/D 4–7 (або обґрунтовано інше).
- [ ] Хвостовик ≤ 12° (ідеально 7–10°), торець ≤ 40 % D або свідомий Kamm.
- [ ] G2-неперервність переходів, без поперечних уступів і щілин.
- [ ] Галтелі на стику, рознесення максимальних товщин, профільований пілон.
- [ ] Оцінка опору (Н, Вт) і порівняння до/після.

## 4. Інтеграція і стандарти
- [ ] Кріплення реальне (вушка/планка/хомут/STC) з розрахунковими навантаженнями.
- [ ] Роз'єм захищений, ЕМС/блискавка враховані, середовище за 810H/DO-160G.
- [ ] Обслуговування без спецінструменту, captive-кріплення, маса для техніка.

## 5. Технологічність
- [ ] Процес виготовлення визначено (композит/фрезерування/друк) і форма йому відповідає.
- [ ] Лінії роз'єму оснастки = лінії дизайну (вздовж потоку).
- [ ] Допуски критичних зон вказано.

## 6. Мова дизайну (defense-tech)
- [ ] Моноліт, форму можна описати одним реченням.
- [ ] Лінії вздовж потоку, ритм кріплень, ряд радіусів.
- [ ] Жодного фейкового декору; матовий CMF зі стандартними кольорами.
- [ ] Вікно — спланований фокус, а не отвір.
- [ ] Не копія чужого продукту.
