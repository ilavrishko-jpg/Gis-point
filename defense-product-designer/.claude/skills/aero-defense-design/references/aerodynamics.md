# Аеродинаміка зовнішніх модулів (pods, fairings, conformal housings)

Мета: мінімальний приріст опору ЛА, прикріплений потік у зоні вікна, відсутність
вібрацій/бафтингу, жодного негативного впливу на керованість, ППД, антени, двигун.

## 1. Режими швидкості — визначає все
| Режим | Типові носії | M | Що головне |
|---|---|---|---|
| Низькі дозвукові | мультиротори, малі БПЛА, < 150 км/год | < 0.15 | маса, площа міделя, тупий торець (донний опір), бокові вітри |
| Дозвукові | літакові БПЛА, Cessna/DA42/King Air, гелікоптери | 0.15–0.5 | хвостовик без зриву, інтерференція, уступи, галтелі |
| Високі дозвукові | бізнес-джети, ISR-джети, ударні БПЛА | 0.5–0.8 | плавність кривизни, правило площ локально, без локальних надзвукових зон |
| Трансзвук і вище | бойові ЛА | > 0.8 | Sears-Haack / von Kármán, правило площ, ударні хвилі — окрема інженерія + CFD обов'язково |

Повітря: ρ₀ = 1.225 кг/м³ (МСА, 0 м), ν₀ ≈ 1.46·10⁻⁵ м²/с. q = ½ρV².

## 2. Тіло обертання — базові пропорції
- **Подовження (fineness ratio) L/D**: мінімум опору на одиницю об'єму ≈ **3–5** (Hoerner);
  для подів з камерою/електронікою практично **4–7**; довше 8–10 — лише якщо треба об'єм
  при малому міделі (висока швидкість).
- **Розподіл**: ніс 20–35 % L · циліндр/макс. товщина 30–50 % · хвостовик 25–35 % L.
- **Макс. товщина** дозвуково — на 30–45 % довжини від носа (ламінарні/NACA-подібні тіла).

### Форми носа
| Форма | Коли | Примітка |
|---|---|---|
| Еліптичний (½-еліпс 2:1–3:1) | дозвук, найпростіший і найкращий | плавний градієнт тиску, добре під вікно вперед |
| Напівсфера | дуже низькі швидкості, купол сенсора | ок до M≈0.3; гарний для концентричного купола |
| Тангенційний огів | універсал | легко будувати в CAD |
| von Kármán (LD-Haack) | M>0.5, «defense» силует | мінімальний хвильовий опір при заданих L і D |
| Конус | лише надзвук | дозвуково гірший за еліпс |
| Тупий плоский | ніколи для зовнішнього модуля | Cd торця ~0.8–1.0 |

### Хвостовик (boattail) — головне джерело опору дозвуково
- Половинний кут **7–10° ідеально, ≤ 12° межа** прикріпленого потоку; > 15° — зрив, бафтинг, донний опір.
- Торець: зменшуй до **≤ 30–40 % діаметра** або закінчуй гостро/майже гостро.
- Тупий торець (наприклад, під роз'єм/кабель) — донний Cd ≈ 0.12–0.2 (від площі торця) у
  дозвуку при турбулентному шарі; рішення: зріз «Kamm tail» при ≥ 50–60 % довжини хвостовика.
- Хвостовик **не** має починатися різким зламом — G2-неперервність (кривизна) з циліндром.

## 3. Інтерференція з носієм (часто > опору самого модуля)
- **Галтелі (fillets)** на стику модуль↔обшивка/пілон: радіус ≥ 0.1–0.15 товщини пілона,
  змінний — більший на задній кромці.
- **Не збігатися** максимальною товщиною модуля з максимальною товщиною крила/фюзеляжу
  (сума збурень → локальне прискорення, при M>0.6 — ударна хвиля). Зсунь вперед/назад.
- **Пілон**: профільований (NACA 00xx, t/c 8–12 %), ніс пілона позаду носа поду, задня кромка — перед хвостовиком.
- **Зазор під'єдного поду до обшивки**: або ≥ 1 товщини граничного шару, або «0» з галтеллю. Середні
  значення (щілина ≈ δ) — найгірше: канал з прискоренням і вихорами.
- **Конформний обтічник**: вхідна рампа ≤ 15–20° (ідеально 10–15°), вихідна ≤ 10–12°,
  бокові ≤ 15°; у плані — «краплина» або «п'ятикутник», вершиною проти потоку; без поперечних уступів.
- Перевір вплив на: **ППД/статичні порти** (не ставити попереду їх на одній лінії),
  антени (затінення діаграми), паливні дренажі, вихлоп, люки, шасі, кут сходу/посадковий кут (tail strike).

## 4. Граничний шар, уступи, щілини
- Товщина турбулентного шару: δ ≈ 0.37·x / Re_x^0.2 (x — від носа поверхні). Число Re_x = V·x/ν.
- **Уступ проти потоку** (forward-facing step) значно гірший за уступ за потоком. Допуски:
  - вперед-спрямований уступ ≤ 0.1–0.2 мм у зоні до 30 % довжини, ≤ 0.5 мм далі;
  - щілини між панелями ≤ 1 мм, герметик заподлицо; поперечні щілини — уникати.
- Кріплення — потайні гвинти (countersunk 100° у авіації) заподлицо ±0.1 мм.
- **Вікно**: заподлицо з поверхнею (flush), рамка без виступу. Заглиблене вікно = порожнина →
  вихрове кільце, пил, бруд, акустика. Якщо заглиблення неминуче — пологий вхідний скіс ≤ 15°.

## 5. Типові Cd (від площі міделя), орієнтири для оцінки
| Конфігурація | Cd |
|---|---|
| Ідеальне тіло обертання L/D 4–6, гладке | 0.04–0.06 |
| Под із плоским вікном заподлицо, гладкий хвостовик | 0.06–0.10 |
| Под з вікном, кріпленнями, роз'ємом на торці | 0.10–0.20 |
| Циліндр з напівсферичним носом і тупим торцем | 0.25–0.40 |
| Кулька/сферичний гімбал | 0.4–0.5 |
| Коробка «як є» | 0.8–1.1 |
+ інтерференція: додай 20–100 % для поду на пілоні/під фюзеляжем без галтелей.

Опір D = q·Cd·S_мід. Потужність на подолання P = D·V. Корисно показувати користувачу у Н і Вт.

## 6. Особливості носіїв
- **Мультиротор**: потік зверху (downwash) у висінні, горизонтальний у польоті під кутом тангажу
  −10…−25°. Форма «краплина вниз» менш важлива за масу і центр мас; камера надир — ізолювати від
  вібрації гвинтів (частоти 80–250 Гц), тримати подалі від струменя гвинтів (бруд, крапля води).
- **Літакові БПЛА**: кут атаки крейсер 2–6° — орієнтуй вісь поду по потоку на крейсері, не по
  будівельній горизонталі; модуль під фюзеляжем — перевір кліренс зльоту/посадки, удар об землю при парашутній посадці.
- **Гелікоптер**: downwash 10–20 м/с у висінні, вібрації N/rev (N — кількість лопатей);
  вікно не під несучим гвинтом прямо; бічний потік до 30–40 вузлів у висінні.
- **Пілотований fixed-wing**: STC-обмеження — під'єдний под на штатних точках або на
  сертифікованому кронштейні (наприклад, step-mount, crew-door mount, belly cargo pod).

## 7. Обледеніння, ерозія, середовище
- Передні кромки і нос — дощова ерозія при V > 300 км/год: еластомерні/поліуретанові
  стрічки, металеві накладки або сапфір/алмазоподібне покриття на вікнах.
- Обледеніння: вікно в нішах і на носі накопичує лід першим; обігрів (ITO або дротова сітка) 1–3 Вт/см² по межі, або розміщення в зоні меншого збору (бічні/нижні поверхні за носом).
- Пісок/пил (MIL-STD-810H м. 510.7) — абразивна ерозія вікна: сапфір, загартоване скло з hard-coat.

## 8. Коли обов'язково CFD / труба
- M > 0.5, або модуль ≥ 10 % міделя фюзеляжу, або біля ППД/повітрозабірника/гвинта,
  або на гелікоптері біля хвостового гвинта. Мінімум: RANS k-ω SST, порівняти «до/після».
- Дешеві кроки: тафти (шерстинки) на макеті в польоті, масляна візуалізація, вібролог акселерометром.
