# Defense Product Designer ✈️

Скіл для Claude: промисловий дизайнер-інженер **аеро-модулів оптичної навігації**, які
кріпляться на літак, гелікоптер або БПЛА ззовні: поди, обтічники, конформні гондоли, кожухи камер.
Стиль — сучасний defense-tech (рівень Anduril / Shield AI): монолітно, функціонально, технічно чесно.

## Що вміє
- **Review / покращення вашого дизайну**: даєте фото, рендер, скетч або CAD-скрін, а скіл повертає
  проблеми за критичністю (🔴🟠🟡⚪), виправлення з цифрами, покращену версію та оцінку «до → після».
- **Концепти від референсів або з нуля**: 2–3 різні стратегії (сертифікаційна / оптимізована / смілива) і рекомендація.
- **Технічна правильність**:
  - аеро: L/D, форма носа, кут хвостовика, інтерференція, уступи, граничний шар, оцінка опору;
  - оптика: розмір і тип вікна, матеріал під спектр, AR/обігрів/вентиляція, камера+IMU, GSD/змаз;
  - інтеграція: кріплення, MIL-STD-810H / 461G, роз'єми, STC.
- **Креслення і 3D**: SVG-креслення (вид збоку і спереду, конус FOV, розміри, метрики), модель OpenSCAD, CSV-профіль для CAD.
- **CMF і рендери**: кольори FS 595 / RAL, матеріали, фініш, маркування, промпти для генераторів і налаштування Blender/KeyShot.

## Як користуватись
**Claude Code** (у цьому репо): відкрийте папку `defense-product-designer/` і напишіть, наприклад:
> «Ось фото нашого модуля VPS під крилом [фото]. Носій ~180 км/год, камера 60°, надир. Покращ дизайн, щоб він був аеро і в стилі Anduril.»

Щоб скіл працював глобально, скопіюйте папку `.claude/skills/aero-defense-design` у `~/.claude/skills/`.

**Claude.ai / Claude Desktop**: заархівуйте папку `aero-defense-design` у zip і завантажте в
Settings → Capabilities → Skills.

**Скрипти напряму:**
```bash
cd .claude/skills/aero-defense-design
python3 scripts/aero_optics_calc.py aero --speed-kmh 180 --alt-m 1500 --length-mm 600 --diameter-mm 140 --boattail-deg 10
python3 scripts/aero_optics_calc.py window --fov-deg 60 --aperture-mm 12 --distance-mm 10
python3 scripts/pod_generator.py --length 600 --diameter 140 --mount pylon --speed-kmh 180 --out out/pod_v1
```

## Обмеження
Розрахунки дають оцінки для концептуального етапу (Hoerner, МСА, Френель). Для M > 0.5, великих модулів
або розміщення біля ППД, повітрозабірника чи гвинта потрібні CFD, продувка і льотні випробування. Відповідність
стандартам скіл не заявляє: він пише, що саме і за яким стандартом треба перевірити.
