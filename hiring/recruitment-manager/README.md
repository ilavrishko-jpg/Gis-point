# Найм · Recruitment Manager (GIS-Point & Мірничий)

Пакет для відбору на роль рекрутера: аналіз ситуації, практичне завдання для кандидата і скоркарта оцінки.

| Файл | Для кого | Що в ньому |
|---|---|---|
| [01-situation-analysis.md](./01-situation-analysis.md) | внутрішній | Стан найму в групі, що вже є по ролі, мапа «ризик у ролі → що перевіряємо завданням» |
| [02-test-task.md](./02-test-task.md) | кандидату | Практичне завдання на 3 години: пошук під BIM-інженера, воронка найму, план 30/60/90 |
| [03-scorecard.md](./03-scorecard.md) | внутрішній | Критерії з вагами, пороги рішення, червоні й зелені прапорці, 6 питань на захист, графік відбору |

**Перед відправкою кандидату** заповнити плейсхолдери `[...]` у `02-test-task.md`: розмір групи, вилка по BIM-інженеру, hiring manager, дата, контакт для здачі.

Джерела аналізу — Notion і Drive групи, перелік у кінці `01-situation-analysis.md`.
