# Найм · Recruitment Manager (GIS-Point & Мірничий)

Пакет для відбору на роль рекрутера: аналіз ситуації і два завдання під різні етапи воронки.

## Етапи

| Етап | Документ | Час кандидата | Час на перевірку |
|---|---|---|---|
| Фільтрування резюме | [04-screening-task.md](./04-screening-task.md) — 12 коротких питань: база + як будуватиме процес і відділ | 30 хв | 5–7 хв за ключем |
| ↳ ключ до нього | [05-screening-key.md](./05-screening-key.md) — бали 0/1/2, пороги, прапорці | | |
| Після інтерв'ю на 60 хв | [02-test-task.md](./02-test-task.md) — пошук під BIM-інженера, воронка з SLA, план 30/60/90 | до 3 год | ~30 хв за скоркартою |
| ↳ скоркарта до нього | [03-scorecard.md](./03-scorecard.md) — критерії з вагами, пороги, 6 питань на захист | | |

Скринінгове завдання не замінює практичне: перше показує, чи знає базу; друге — чи вміє нею користуватись руками.

## Контекст

[01-situation-analysis.md](./01-situation-analysis.md) — стан найму в групі, розбіжність акцентів між офером і вакансією, мапа «ризик у ролі → що перевіряємо завданням». Джерела — Notion і Drive групи, перелік у кінці документа.

**Перед відправкою кандидату** заповнити плейсхолдери `[...]`: контакт для здачі й дедлайн — у скринінговому завданні; розмір групи, вилка по BIM-інженеру, hiring manager — у практичному.
