# ДВІ ВОРОНКИ ВАЛІДАЦІЇ НА СТЕНДІ · Intergeo 2026

**Для кого:** менеджер, який стоїть на стенді. **Мета:** витрачати час тільки на валідних.
**Головне правило:** не пройшов ворота — **виходиш за 30 секунд**. Не тримай розмову з ввічливості.

```
              ЛЮДИНА ПІДІЙШЛА
                     │
         ┌───────────┴───────────┐
         │  0 · ВІДСІЮВАЧ 10 сек │  ──► СТОП
         └───────────┬───────────┘
                     │
         ┌───────────┴───────────┐
         │  0 · РОЗВИЛКА 20 сек  │
         └─────┬───────────┬─────┘
               │           │
        ВОРОНКА A     ВОРОНКА B
       ВИРОБНИЦТВО       СОФТ
        (Unit 1)       (Unit 2)
          A1 ─► A2 ─► A3     B1 ─► B2 ─► B3
               │           │
               └─── ВАЛІДНИЙ ───┘
```

## 0 · ВІДСІЮВАЧ — 10 секунд, до будь-якої воронки

Це не питання, це те, що ти **чуєш і бачиш** у перші секунди. Збіг → одразу вихід.

| Що бачиш / чуєш | Фраза на вихід |
| :-- | :-- |
| Продає нам щось | *"We're not buying at the show. Leave a card, I'll pass it on."* |
| Шукає роботу, студент, CV в руках | *"We hire through the website — drop your CV there."* |
| Аутсорс-агенція або стафінг (будь-яка країна) | *"Thanks — we're not looking for suppliers."* |
| Компанія до 10 людей | *"Here's my card if things change."* |
| «Скільки коштує година?» замість розмови | *"Depends on scope — I'll send you something after the show."* |
| Дані не можуть виходити за межі їхньої країни або периметра | *"Sounds like we're not the right fit."* |
| Кінцевий покупець — держава або університет | *"Sounds like we're not the right fit."* |

> *"What does {Company} actually do — do you deliver geodata work to clients, or do you build and sell your own software or product?"*

| Відповідь | Куди |
| :-- | :-- |
| Знімають, обробляють, віддають клієнту результат | **ВОРОНКА A** |

# ВОРОНКА A · ВИРОБНИЦТВО (Unit 1)

Для геодезичних, ГІС і сканувальних фірм. Продаємо **потужність обробки**.

### A1 · Чи вони взагалі віддають клієнту готовий продукт — 30 сек

> *"What do you hand your client — raw data, or the finished deliverable?"*

| | |
| :-- | :-- |
| ✅ **ДАЛІ** | Готові дедліверабли: класифікована хмара, DEM/DTM/DSM, вектор, орто, BIM-модель, CAD. **Навіть якщо самі не обробляють** — головне, що вони за це відповідають |
| ❌ **СТОП** | Віддають тільки сирі дані, обробку робить клієнт. Їм наша потужність не потрібна |

### A2 · Чи в них болить потужність — 60 сек

> *"When more work comes in than the team can process — what happens?"*

| | |
| :-- | :-- |
| ✅ **ДАЛІ** | Овертайми · беруть фрілансерів · віддають підряднику · відмовляються від тендерів · зриваються дедлайни · **польові інженери сидять на камералці** ← найгарячіше |
| ❌ **СТОП** | «Такого не буває, принципово все самі, команда недозавантажена» |

> Той, хто **вже** віддає обробку назовні, — не «партнер», а найтепліший лід. Питай далі: *"Who do you use now — and what would you change about it?"*

### A3 · Чи є конкретна робота і хто вирішує — 60 сек

> *"What's the next project where this would come up — and who decides on your side?"*

| | |
| :-- | :-- |
| ✅ **ВАЛІДНИЙ** | Названий проєкт **+ дата** + ім'я або роль ЛПР |
| 🟡 **H · nurture** | Біль є, але «коли з'явиться» без дати → у сіквенс, не в пайплайн |
| ❌ **СТОП** | Разова дрібниця без повторення |

**Хто ЛПР:** 30–500 → Head of Production & Ops · GIS Manager · Technical Director. До 30 → власник.

# ВОРОНКА B · СОФТ (Unit 2)

Для продуктових і софтверних компаній у гео. Продаємо **потужність розробки**.

### B1 · Чи в них є свій софт — 30 сек

> *"Do you build any of your own software — a portal, plugins, internal tools?"*

| | |
| :-- | :-- |
| ✅ **ДАЛІ** | Будують · планують почати · все покупне, **але щось не влаштовує** |
| ❌ **→ ВОРОНКА A** | Все покупне і все влаштовує. Не стоп — перевір їх воронкою A |

### B2 · Що заблоковано за браком розробки — 60 сек

> *"What's on your roadmap that's stuck waiting for dev capacity?"*

| | |
| :-- | :-- |
| ✅ **ДАЛІ** | Названа конкретна річ: портал для клієнтів · пайплайн обробки · інтеграція · ML-модель · міграція з ArcMap · вихід із Esri |
| ❌ **СТОП** | «Нічого, все встигаємо, команда закриває» |

### B3 · Хто власник і коли — 60 сек

> *"Who owns that on your side — and when would you want it live?"*

| | |
| :-- | :-- |
| ✅ **ВАЛІДНИЙ** | CTO · Head of Product · Founder **+ дата або квартал** |
| 🟡 **H · nurture** | Власник є, дати немає |
| ❌ **СТОП** | Ні власника, ні дати — це розмова «колись» |

## ЩО РОБИТИ З ВАЛІДНИМ — 3 дії, більше нічого

1. **Записати 6 полів:** компанія · ім'я і роль · воронка A/B/K · біль **їхніми словами** · дата наступного проєкту · що пообіцяв.
2. **Домовитись про наступний крок із датою.** Не «спишемось» — конкретно: *"I'll send you X on Friday — does Tuesday work for a 30-minute call?"*
3. **Дати матеріал:** A → GEOSPATIAL або Construction one-pager. B → QR на `gis-point.com/case-studies`, фільтр Software Engineering.

**Ніколи на стенді:** не називаємо ставки й ціни · не обіцяємо термінів («уточню в тех-команди») · не кажемо «IT», кажемо **software development**.

**Фраза, яка відкриває обидві воронки:**
> *"We extend your team, we never compete with you, and your code and IP stay yours."*

## ТАЙМ-БЮДЖЕТ — за ним себе перевіряй

| Кого зустрів | Скільки часу |
| :-- | :-- |
| Відсіювач спрацював | **10 секунд** |
| Впав на воротах 1 | **30 секунд** |
| Впав на воротах 2 або 3 | **до 2 хвилин** |
| Валідний | **до 5 хвилин**, далі — окрема зустріч, не на стенді |

Якщо розмова йде 10 хвилин і ти ще не знаєш, валідний він чи ні — **він невалідний**. Виходь.
