# Навчання UC Berkeley

Розділ для навчальних матеріалів UC Berkeley: накопичення джерел, формування
методички та підготовка презентації.

## Структура

| Папка | Призначення |
|-------|-------------|
| [`materials/`](./materials/) | Вихідні навчальні матеріали (конспекти, нотатки, транскрипти лекцій, ресурси). Додаються по мірі надходження. |
| [`methodology/`](./methodology/) | Сформована методичка навчання на основі накопичених матеріалів. |
| [`presentation/`](./presentation/) | Матеріали презентації (структура слайдів, тексти, фінальні файли). |

## Як додавати матеріали

1. Кожен новий блок — окремий `.md` файл у `materials/` з описовою назвою
   (напр. `01-lecture-intro.md`, `02-topic-name.md`).
2. Коли матеріалу достатньо — формуємо методичку в `methodology/`.
3. На основі методички — презентацію в `presentation/`.

## Статус

- [ ] Накопичення вихідних матеріалів (в процесі)
- [ ] Формування методички
- [ ] Підготовка презентації

> **Наступний крок:** додати перший навчальний матеріал у `materials/`.
