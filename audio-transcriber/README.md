# Транскрипція аудіо → український текст

Програма перетворює аудіозапис (диктофон iPhone `.m4a`, а також `.mp3`, `.wav`, `.mp4` тощо)
на текст українською. Працює **локально** на вашому комп'ютері через
[faster-whisper](https://github.com/SYSTRAN/faster-whisper): запис нікуди не надсилається,
обмежень на розмір файлу немає, оплата не потрібна.

## Встановлення (один раз)

Потрібен Python 3.9+ ([python.org](https://www.python.org/downloads/)).

```bash
cd audio-transcriber
pip install -r requirements.txt
```

## Запуск

```bash
python transcribe.py "Новий запис.m4a"
```

Під час першого запуску завантажиться модель (~1.5 ГБ), далі інтернет не потрібен.
Поруч з аудіофайлом з'являться:

| Файл | Що всередині |
|---|---|
| `Новий запис.txt` | чистий текст |
| `Новий запис.timestamps.txt` | текст із часом кожної фрази `[00:12:34]` |
| `Новий запис.srt` | субтитри |

Текст пишеться у файли одразу під час роботи, тож якщо перервати (Ctrl+C) —
уже розпізнана частина збережеться.

## Корисні параметри

```bash
# найвища точність (у 3–5 разів повільніше)
python transcribe.py запис.m4a --model large-v3

# швидше, але менш точно (слабкий ноутбук)
python transcribe.py запис.m4a --model small

# підказати імена й терміни, щоб вони писалися правильно
python transcribe.py запис.m4a --prompt "GIS-Point, Scaling Up, Odoo, імена учасників"

# інша мова запису
python transcribe.py запис.m4a --language en
```

## Скільки це триває

Запис диктофона iPhone на 250 МБ — це приблизно 4–8 годин звуку.
Орієнтовно з типовою моделлю `large-v3-turbo`:

- відеокарта NVIDIA — 10–20 хвилин (використовується автоматично);
- сучасний ноутбук без відеокарти (у т.ч. Mac) — приблизно стільки ж, скільки триває сам запис,
  або в 2–3 рази швидше. Зручно запускати на ніч.

## Як перенести запис з iPhone

Диктофон → запис → «…» → «Зберегти у Файли» / AirDrop / надіслати собі; на комп'ютері
це буде файл `.m4a`.
