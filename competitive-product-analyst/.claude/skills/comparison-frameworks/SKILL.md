# Comparison Frameworks — фреймворки порівняння

## Коли застосовувати
Крок Structure (SKILLSET §4, §6). Мета — звести сирі факти в структуру, придатну для рішення.

## Підбір фреймворку під задачу
- **Feature Comparison Matrix** — базовий. Рядки = **сценарії/JTBD** (не сирі фічі), стовпці = гравці.
  Оцінка 1–5 або ✓/◑/✗ + коментар із джерелом.
- **SWOT** — по кожному конкуренту (внутрішні S/W + зовнішні O/T).
- **Positioning / Perceptual Map** — 2 осі під ринок (напр. ціна × точність, простота × потужність);
  розстав усіх гравців + нас → знайди вільний простір.
- **Kano** — фічі як базові / очікувані / захопливі (де інвестувати).
- **Value Curve (Blue Ocean)** — крива цінності за 6–8 факторами; де ми пласкі/де можна відірватись.
- **Porter's Five Forces** — коли питання про структуру галузі/бар'єри.
- **Win/Loss** — коли є дані по угодах: чому виграли/програли проти конкурента.

## Виміри порівняння (мінімум, SKILLSET §6)
Функції за сценаріями · Ціна та **TCO** · Точність/якість (виміряні) · Time-to-value · Екосистема ·
Надійність/підтримка · Диференціатори/moats · Собівартість-маржа.

## Алгоритм
1. Обери 1 наскрізну матрицю (Feature/Spec за сценаріями) для всіх гравців.
2. Додай SWOT на кожного + одну Positioning Map на ринок.
3. Виділи **диференціатори** (що складно скопіювати) і **вразливості** кожного.
4. Кожну клітинку підкріпи джерелом; порожнє = «невідомо», не залишай тихо.

## Шаблон матриці
```
Вимір / сценарій | Вага | Ми | Конкурент A | Конкурент B | Коментар + джерело
Разом (зважено)  |      | __ | __          | __          |
```

## Вихід
Заповнені матриці + SWOT + позиційна карта → передаються у `analyst-report`.
