# Перевірки

## Дані

```
python3 test/check_data.py <тека з вихідними .xlsx>
```

Звіряє базу, вшиту в `index.html`, з вивантаженнями поле за полем: кількість
рядків за джерелами, збіг кожної колонки, чи не втратився жоден «Коментар» при
розборі на Гачок / Сегмент / Пріоритет, чи збіглася кількість зустрічей.
Виходить з кодом 1 при першій розбіжності. Запускати після кожного
перескладання бази через `data/build_base.py`.

## Скринінг

```
node test/screening.test.mjs
```

56 перевірок логіки без браузера: набори питань за типами (3–5, впорядковані),
`passWhen` для number / single / text із галочкою / date з вікном і без,
скоринг з дедуплікацією гіпотез, межі вердиктів (4 -> LEAD, 6 -> HOT,
дискваліфікатор при 5 -> STOP), маршрути й рекомендації, правила комунікації
в текстах.

## Інтерфейс

```
npm i playwright
node test/ui.test.mjs
```

164 перевірки: пошук (назва, людина, текст довідки, код стенда, цифровий режим),
фільтри, розклад зустрічей, картка ліда, журнал контактів з редагуванням і
видаленням, підсумок, збереження після перезавантаження, експорт CSV з
розбором назад, ручне зіставлення колонок, імпорт файлу поверх вшитої бази,
світла й темна теми, повний прохід скринінгу до вердикту, відсутність винятків.

Chromium береться з `CHROME_PATH`, інакше зі стандартної теки Playwright.
Сторінка обгортається у `<!doctype>…<body>` так само, як це робить хостинг
артефактів, тож тестується рівно те, що бачить користувач.
