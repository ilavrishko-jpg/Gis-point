## Гіпотези для перевірки на цій зустрічі (внутрішнє, не показувати)

1. **ТОЧНІСТЬ** — 5–30 м закриває більшість місій; <5 м треба лише під strike. → підтв. / спрост.
2. **SWaP** — існує чіткий габаритно-енергетичний «стеля», нижче якої конкуренти не влазять. → підтв. / спрост.
3. **ІНТЕГРАЦІЯ** — головний біль не залізо, а fusion + тижні інженерів на інтеграцію. → підтв. / спрост.
4. **ЦІНА-ТРИГЕР** — перехід від конкурента відбувається при X% дешевше АБО кращій точності/ночі. → значення X: ______
5. **ДЕНЬ/НІЧ** — нічна (ІЧ) конфігурація має окрему цінову й попитну динаміку. → підтв. / спрост.
