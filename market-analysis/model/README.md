# Перевірка моделі

`verify-model.py` — мінімальний обчислювач формул Excel. Читає `../unit-economics-model.xlsx`,
розкриває всі формули (посилання, SUM, SUMPRODUCT, IF) і звіряє 54 ключові комірки
з еталонними значеннями.

```bash
pip install openpyxl && python3 verify-model.py
```

Очікуваний результат: `РЕЗУЛЬТАТ: 54/54 перевірок пройдено`.

Потрібен, бо LibreOffice у CI-середовищі не завантажує xlsx, а без перерахунку
легко не помітити зсунуте посилання на комірку — саме така помилка й була знайдена
цим скриптом на етапі збирання моделі.
