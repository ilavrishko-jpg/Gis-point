## ⚠️ Що тут факт, а що модель

| Що | Статус |
|---|---|
| Обсяги ринків, курс, статистика галузей | Публічні джерела з посиланнями |
| Ціни на послуги | **Перевірені публічні прайси** — але зі сніпетів пошуку, бо проксі блокує сайти напряму |
| Utilization, структура витрат, ціни підписок | **Ринково-типові припущення**, не ваші дані |
| «База 2026» у P&L | **Реконструкція**, а не ваша звітність |

**Пʼять цифр, які треба замінити на свої:**

1. У якій структурі витрат працюють бригади — «важкій» чи «легкій» (різниця **620 тис. грн на бригаду**)
2. Фактичний utilization польових бригад (модель: 62%)
3. Фактична середня денна ставка бригади (модель: 14 000 грн геодезія, 16 000 грн геологія)
4. Фактична ставка продажу IT-години на ваших договорах (модель: $26 — найслабше місце)
5. Фактичний SG&A як % від виручки (модель: 16%)

Це жовті комірки аркуша «1.Припущення» в [`unit-economics-model.xlsx`](./unit-economics-model.xlsx).

## Коротка відповідь: куди рухатися на внутрішньому ринку

**Ядро — мережі й комунальна інфраструктура. Двигун поруч — інфраструктурні геодані.
Геодезія — не зростання, а структура витрат. Геологія — рішення, а не інерція.**

Валовий прибуток, який приносить один співробітник за рік:

| ІТ / цифра для агро | 41 942 | ✗ LTV/CAC 1,8 — ринок зайнятий |
| Надра й карʼєри: DaaS | 41 010 | ★ але ринок замалий сам по собі |
| **Мережі й комунальна інфраструктура** | **40 932** | ★★★ **ядро** — масштаб + економіка |
| **Дорожники та інфраструктура** | **34 330** | ★★ разом з надрами — одна технологія |
| Розмінування | 32 039 | ◐ опція, політичний ризик |
| ІТ для будівельників | 31 456 | ★ SAM лише 337 млн грн |
| Громади | 21 748 | ✗ демпінг, дрібні чеки |
| Топогеодезія | 13 126 | ● кеш і канал, не зростання |

## Чотири висновки

1. **Геологія не має ціни, за якої окупається.** Ринок платить 16 000 грн за бригадо-день.
   Для беззбитковості при 70% завантаження потрібно ~29 000. Розрив 1,8 раза — і він не закривається
   ані завантаженням, ані переговорами, ані списанням установки. Це арифметика, не думка.

2. **У геодезії головний важіль — не ціна і не завантаження, а власна структура витрат.**
   Та сама ринкова ставка 14 000 грн дає −15% маржі на «важкій» структурі (штат, лізинг, нове
   обладнання) і +16% на «легкій» (ФОП, самортизоване обладнання). Різниця — 620 тис. грн на бригаду.

3. **Продавати IT-години українському замовнику неможливо з прибутком.** Собівартість години
   $35,3, ринок платить $26. Для внутрішнього ринку працює тільки продукт або підписка.

4. **Без експорту нижню межу не тримає ніщо.** У сценарії «ескалація / зрив фінансування»
   виручка падає удвічі — до 130 млн грн, бо всі шість напрямків живляться з одного джерела:
   бюджету й донорських грошей. Це ціна рішення, і її треба закривати подушкою кешу.
