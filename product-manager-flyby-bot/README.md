# Product Manager Bot «FlyBy» 🛩️

Бот-помічник продакт-менеджера для напрямку **БПЛА (fly by)** GIS-Point. Будує повноцінну
систему визначення **всіх етапів продукту — від ідеї до реалізації** — і веде по ній крок за кроком.

Методологія — **дискавері-дисципліна продукту** (Double Diamond: Discover · Define · Develop ·
Deliver) + gate на кожному переході етапу. Кожен етап має вхідний і вихідний критерій (гейт) та
конкретний артефакт-доказ: без нього до наступного етапу не йдемо.

## Що вміє
- **Веде продукт по 6 етапах:** Ідея → Дослідження → Визначення → Валідація → Реалізація → Запуск.
- **Збирає ринок виробників БПЛА:** формує лонгліст 10–20 виробників і мапить, скільки їх в Україні.
- **Складає опитувальник** із трьох блоків — технічні · бюрократично-регуляторні · фінансові питання.
- **Проводить опитування/інтерв'ю** виробників і зводить відповіді у структуровані інсайти.
- **До-формовує продукт:** вимоги → концепт → бізнес-кейс → дорожня карта → MVP → запуск.
- **Тримає gate-дисципліну:** не пускає далі, доки етап не дав доказ і не пройшов критерій виходу.
- **Самонавчається:** фіксує прогалини й, коли вони повторюються, пропонує нову навичку/агента (через PR).

## Швидкий старт
> Хочеш одразу результат — почни з **`PLAN.md`**: це покроковий план від ідеї до реалізації,
> який викликає потрібні навички в правильному порядку.

## Структура
```
product-manager-flyby-bot/
├── CLAUDE.md                  # мозок: як бот працює і самовдосконалюється
├── PLAN.md                    # покроковий план «від ідеї до реалізації» (головний сценарій)
├── CHANGELOG.md               # журнал самонавчання (довготривала памʼять)
├── .claude/
│   ├── settings.json
│   ├── skills/                # 11 продуктових навичок + skill-author + agent-architect
│   └── agents/                # research / product / delivery-agent
├── governance/                # цикл навчання, стандарти, рубрики, реєстр, беклог, шаблони
└── .github/workflows/bot.yml  # інтерактивний бот на GitHub (потрібен секрет ANTHROPIC_API_KEY)
```

## Як користуватися
**Локально (Claude Code):** відкрий теку `product-manager-flyby-bot/` — навички й агенти
підхопляться автоматично. Скажи, наприклад: «збери 15 виробників БПЛА» або «склади опитувальник».

**На GitHub (інтерактивно):**
1. Додай секрет `ANTHROPIC_API_KEY` (Settings → Secrets and variables → Actions).
2. Створи Issue або коментар зі згадкою `@claude` і запитом.
3. Бот відповість, спираючись на навички/агентів цього репо, і за потреби подасть PR.

## Межі (чесно)
Бот не переписує себе автономно. «Навчання» — це пропозиції змін (PR) з одним підтвердженням
власника. Нові навички/агенти додаються лише за доказами повторюваності, а не «про запас».
Дані про виробників бот не вигадує: якщо факту немає — позначає як гіпотезу для перевірки.
