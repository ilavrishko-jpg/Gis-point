# Product Definition Canvas (формування продукту)

## Коли застосовувати
Коли вимоги зведені (Етап 2.1) і треба з них зібрати цілісний продукт — «що саме ми будуємо, для кого
і чим ми кращі». Це фінальний артефакт визначення перед валідацією економіки.

## Кроки
1. **Сегмент** — для кого точно (не «всі»), звузь до Core Customer.
2. **Ціннісна пропозиція** — одна фраза «для <сегмент> / <цінність> / чим кращі за альтернативу».
3. **Обсяг MVP** — мінімум, що доводить гіпотезу; усе решта у «пізніше».
4. **Диференціація** — 2–3 речі, які робимо інакше (спираючись на інсайти й мапу ринку).
5. **Ризики й припущення, що лишились** — що ще може завалити продукт.
6. Звірся зі специфікацією: кожен must-елемент відображений; нічого зайвого поза MVP.

## Шаблон (1 сторінка)
```
Продукт: ___
Сегмент (Core Customer): ___
Ціннісна пропозиція: для ___ ми даємо ___, і на відміну від ___ ми ___.
Обсяг MVP (must): ___
Поза MVP (пізніше): ___
Диференціація (2–3): ___
Ключові ризики, що лишились: ___
Метрика успіху продукту: ___
```

## Правила якості
- Якщо сегмент — «усі», продукт не визначено. Звужуй.
- MVP має вміщатись у бюджет часу/грошей Етапу 3; усе «cool, але не зараз» — у «пізніше».
- Спирайся на `geo-it-positioning`/`gtm-strategy` (зовнішні), якщо треба гостре позиціонування.

## Gate етапу (вхід/вихід)
- **Вхід:** є специфікація вимог.
- **Вихід:** є фраза «для кого / яка цінність / чим кращі»; MVP-скоуп реалістичний за бюджетом.
