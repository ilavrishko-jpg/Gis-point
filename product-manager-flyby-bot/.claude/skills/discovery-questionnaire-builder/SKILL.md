# Discovery Questionnaire Builder (опитувальник виробників)

## Коли застосовувати
Перед опитуванням виробників (крок 1.2). Треба перетворити ризиковані припущення з Етапу 0 на
конкретні питання, згруповані у три блоки, щоб кожне питання щось вирішувало.

## Принцип
Кожне питання прив'язане до припущення/рішення, яке воно закриває. Питання відкриті (не «так/ні»)
там, де потрібен інсайт. Уникай навідних формулювань.

## Три блоки питань (база — адаптуй під продукт)
**1. Технічні**
- Тип платформи (FPV/крило/мультиротор/VTOL) і чому саме він?
- Корисне навантаження, дальність, час/висота польоту, злітна маса?
- Канали зв'язку й частоти; що з керуванням в умовах РЕБ?
- Навігація: GNSS / інерціальна / оптична / без GPS?
- Автопілот і ПЗ: своє чи стороннє? Оновлення прошивок?
- Локалізація компонентів (%), критичні залежності від імпорту?
- Реальна серійність зараз і стеля потужності?

**2. Бюрократично-регуляторні**
- Чи є кодифікація (NCAGE/NSN), допуск/кваліфікація Міноборони?
- Ліцензія на розробку/виробництво ОВТ; статус у реєстрах ОПК?
- Дозволи на частоти (УДЦР); сертифікація/ДСТУ?
- Експортний контроль, ITAR-компоненти, обмеження на постачання?
- Досвід держконтрактів/ДК 021:2015, участь у Brave1/тендерах?

**3. Фінансові**
- Ціна за одиницю й мінімальна партія?
- Умови оплати/аванс, строк постачання?
- Орієнтовна собівартість і її драйвери?
- Виробнича потужність на місяць; вузьке місце масштабування?
- Гарантія, обслуговування, потреба в обіговому капіталі?

## Кроки
1. Витягни припущення з one-pager ідеї; познач, який блок їх закриває.
2. Наповни три блоки питаннями (база вище + специфіка продукту). Прибери зайве — лише те, що вирішує.
3. Зроби **дві версії**: коротка (5–7 питань для холодного контакту) і повна (для інтерв'ю).
4. Додай вступ (хто ми, навіщо, скільки часу) і згоду на використання відповідей.

## Шаблон
```
Вступ (2 речення: хто ми · навіщо · ~час):
Блок 1. Технічні: Q1… Q2…  → закриває припущення: ___
Блок 2. Регуляторні: Q1… Q2…  → закриває припущення: ___
Блок 3. Фінансові: Q1… Q2…  → закриває припущення: ___
Коротка версія (5–7 питань): ___
```

## Gate етапу (вхід/вихід)
- **Вхід:** є ризиковані припущення з Етапу 0 і лонгліст виробників.
- **Вихід:** кожен блок покриває свій ризик; є коротка й повна версії; питання відкриті, не навідні.

## Вихід
Опитувальник (коротка + повна версії) готовий для `manufacturer-interview-runner`.
