# FlyBy — Фірмова айдентика (єдина система оформлення)
> Застосовується до ВСІХ матеріалів проєкту: інвестор-меморандум, one-pager, дека, звіти.
> ⚠️ Це **запропонована** система (сайт flyby.gis-point.com недоступний із середовища).
> Надайте точні HEX/лого/шрифт — і всі матеріали оновляться за один прохід.

## Концепція
Оборонний навігаційний застій: HUD / телеметрія / топографічна сітка. Стримано, точно, «інструментально».
Один сміливий акцент (сигнальний янтарний) на спокійному сланцевому тлі.

## Кольори (токени)
| Токен | HEX | Застосування |
|---|---|---|
| `navy` (основний темний) | `#0E1F2D` | H1, шапки, темні блоки |
| `amber` (акцент) | `#C77C08` | H2-лінії, ключові цифри, «очі», лінійки |
| `amber-light` | `#E4930B` | акцент на темному тлі |
| `ink` (текст) | `#1B2733` | основний текст |
| `muted` | `#5C6873` | підписи, примітки |
| `hair` | `#D8DCD8` | лінії, межі таблиць |
| `panel` | `#F5F6F4` | світлі панелі |
| `accent-panel` | `#FBF1DF` | виноски-акценти |
| `good` | `#2F8F5B` | перевірено `[P]` |
| `bad` | `#C23B4E` | спростовано |

## Типографіка
- **Заголовки:** Oswald / Montserrat (умовно-технічний гротеск), напівжирний, трекінг +2%.
- **Текст:** Roboto / Arial, 11 pt, інтерліньяж 1.5.
- **Дані/цифри/лейбли:** Roboto Mono (телеметрія, табличні числа).

## Правила
- Один акцент — янтарний. Не додавати другий яскравий колір (green/red лише для статусів `[P]`/спростовано).
- Числа — моноширинним, вирівняні по правому краю в таблицях.
- Позначки доказовості `[P]/[S]/[M]/[F]` — завжди присутні біля цифр.
- Ієрархія: eyebrow (моно, янтарний, caps) → H1 (navy) → H2 (з янтарною лінією) → текст.

## Активи проєкту (єдиний стиль)
1. `INVESTOR-REPORT-FlyBy.md` — меморандум (текст).
2. Google Doc — брендований меморандум (створюється зараз).
3. `flyby-investor-onepager.html` — візуальний one-pager (янтар/сланець) + Артефакт.
4. `PROOF-*.md` — аналітичні звіти з тими самими позначками доказовості.
5. Цей стиль-гайд — джерело правди для кольорів/шрифтів.
