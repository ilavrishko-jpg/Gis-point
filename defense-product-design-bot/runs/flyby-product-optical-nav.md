# «fly by» · Уточнений продукт — оптична навігація без GNSS для БПЛА

> Уточнення власника (2026-08-12): «fly by» = **оптична навігаційна система, що обчислює координати
> (GPS-позицію) без GNSS для БПЛА**. Це знімає питання A/B/C з Фази 2: продукт — **навігаційний
> модуль (ПЗ + камера/обчислювач)**, який інтегрують виробники БПЛА. Загострена Definition нижче.

## Продукт одним реченням
Бортовий модуль, що дає БПЛА **абсолютну координату без супутника** — зіставляючи зображення з
камери з геоприв'язаними картами/ортофото/супутником GIS-Point — стійкий до глушіння й спуфінгу.

## Як це працює (категорія)
- **Абсолютне візуальне позиціонування (scene/image matching):** кадр з камери → зіставлення з
  геоприв'язаною базою (супутник/ортофото) → абсолютні координати (lat/long, MGRS). **Не дрейфує** — це наш клас.
- vs **відносне (visual odometry / SLAM / INS):** дешеве, але накопичує дрейф. Наш модуль дає йому «якір» абсолютної позиції.
- **Вихід — як GPS:** модуль емулює GNSS-повідомлення (напр. NMEA) → drop-in для наявних автопілотів.

## Чому це найсильніший збіг для GIS-Point
Ядро продукту — **не камера, а геоприв'язана база й алгоритм зіставлення**. Це геопросторова
експертиза GIS-Point (супутник/ортофото, картографія, дешифрування). За джерелами, саме на «трові»
супутникових знімків будують абсолютне позиціонування без GPS (напр. Vantor) — у вас цей актив уже є.

## Хто клієнт (важливий розворот)
**Лонгліст виробників із Discovery 1.2 — тепер не конкуренти, а КЛІЄНТИ.** Модуль інтегрують у крило
mid-strike + ISR (Fire Point, UkrJet, Terminal Autonomy, Deviro, Warbirds…). Плюс оператори як вимогодавці.
- **Dual-use (велика перевага):** цивільні дрони (картографія, агро, логістика, енергетика, НС) — той самий модуль без ударної частини. Ринок ширший за оборонний.

## Конкурентна/аналогова картина (реальна)
- **OSCAR** (optical system w/ auto relocalization) — зіставлення з мапованими орієнтирами, стійке до глушіння/спуфінгу.
- **UAV Navigation — GNSS-Denied Kit** (AHRS + visual nav, dead reckoning з мін. дрейфом).
- **Vantor** — абсолютне позиціонування на власному масиві супутникових знімків.
- **Академічні методи** зіставлення: SuperPoint+SuperGlue, LoFTR, matching з ортофото/супутником.
- Висновок: клас підтверджений, конкуренція є → диференціація GIS-Point = **якість/актуальність геобази + робастність зіставлення (ніч/сезон/масштаб)**.

## Бізнес-модель (краща за «залізо»)
- **B2B2mil компонент:** ліцензія за борт (per-airframe) + постачання модуля + **recurring сервіс геобази** (оновлення знімків/покриття).
- Оборотний капітал нижчий за планер; маржа ПЗ/даних висока; дублювання в **цивільний dual-use** розширює ринок.
- Ризик: залежність від інтеграції з чужими автопілотами → мінімізувати еталонними інтеграціями (N7).

## Рішення go/no-go
**Схиляюсь до GO.** Причини: (1) найточніший збіг із моатом GIS-Point (геобаза), (2) клієнти вже є
(лонгліст), (3) сильний dual-use, (4) низький оборотний капітал. Умова go: підтвердити на опитуванні
2–3 виробників **готовність інтегрувати й платити per-airframe** + узгодити цільову похибку N1. Фінал — за власником (ворота 2→3).

## Що змінюється у Discovery (треба до-зробити)
1. **Перепризначити опитувальник** з «вивчаємо виробників» на **customer discovery**: як зараз вирішують
   GNSS-denied? який автопілот? яка потрібна похибка? хто платить (виробник чи замовник)? інтеграційний інтерфейс?
2. Опитати 2–3 виробники з лонглісту як **потенційних клієнтів** (Fire Point / UkrJet / Terminal Autonomy / Deviro).
3. Уточнити N1 (цільова похибка) і N7 (еталонний автопілот) — це відкриває Фазу 3.

## Ворота 2→3 (статус)
- ❗ Продукт визначено — ✅ (оптична нав-система без GNSS).
- ❗ Пріоритет №1 — ✅ (абсолютна позиція без GNSS + GNSS-емуляція на вихід).
- ❗ Degraded baseline — ✅ (глушіння/спуфінг, ніч, офлайн-геобаза).
- ❗ Trade-off — ⏳ (точність ↔ SWaP/латентність/ціна) — узгодити з власником.
- ❗ Фінансовий gate — ⏳ (підтвердити per-airframe готовність 2–3 клієнтів).

**Наступний крок (Фаза 3, коли закриєш ⏳):** дизайн через `geospatial-c2-ux` + `defense-ux-design` —
UX **впевненості позиції** для оператора/GCS (джерело позиції: збіг vs INS-дедрекон, якість збігу,
оцінка дрейфу, стани «нема збігу/деградація») + інтеграційний контракт для виробника.
