# Частки партнерів та розподіл інвестицій

## Коли застосовувати
- «Нас троє — як поділити частки справедливо?»
- «Один вклав час, інший гроші, третій продажі — як зрівняти?»
- «Моя компанія фінансує спільний продукт — як не подарувати вартість іншим партнерам?»
- Треба зафіксувати домовленість, щоб не було спору пізніше.

## Крок 1 — Веди РЕЄСТР ВНЕСКІВ (contribution ledger)
Таблиця: партнер · тип внеску (кеш / час-розробка / час-продажі / IP / клієнти) · обсяг · оцінка $.
- Sweat оцінюй за ринковою ставкою ролі × години (розробка, продажі, дослідження — різні ставки).
- Онови реєстр щокварталу — це жива основа справедливості часток.

## Крок 2 — True-up до узгоджених часток
Якщо ціль — рівні частки (напр. 1/3 : 1/3 : 1/3), а внески поки нерівні:
- визнач, хто «недовклав», і зафіксуй, ЧИМ він добирає (напр. N місяців продажів/розробки);
- частки закріплюються ПІСЛЯ досягнення парності (vesting), не авансом.

## Крок 3 — Розділяй КЕШ і SWEAT-канали
- Sweat (час партнера особисто) → формує EQUITY (частку).
- Кеш ВІД КОМПАНІЇ партнера (не з його кишені) → це НЕ автоматично його особистий equity.
  Це гроші третьої кишені (компанії) → потребують окремого повернення (позика / royalty-free / маржа),
  інакше компанія дарує вартість решті партнерів. Див. `group-structure-and-ip-ownership`.

## Крок 4 — Фінансування спільної розробки (щоб ніхто не програв)
Коли компанія одного з партнерів платить за спільний актив:
- **Dev-позика** (рекомендовано на старті): компанія дає $C у борг спільній фірмі; повертається з доходу
  активу ПЕРЕД розподілом прибутку 1/3:1/3:1/3. Потім усі ділять порівну. Ніхто не free-rider.
- Альтернативи: equity-кредит (росте частка) або royalty-free право користування.

## Крок 5 — Конфлікт інтересів і підпис
- Умови угоди між «моєю компанією» і «спільною фірмою» підтверджують ВСІ партнери спільної фірми.
- Зафіксуй у короткій партнерській угоді: частки · vesting/true-up · модель фінансування · маржа/роялті · вихід.

## Шаблон (заповнити)
```
Партнери й цільові частки: …
Реєстр внесків (кеш/sweat, оцінка $): …
True-up: хто добирає й чим, до якої дати: …
Фінансування розробки: [позика C=$… / equity / royalty-free], умови повернення: …
Маржа продавця / роялті власника: … % / … %
Хто підписує / підтверджує: …
```

## Калібрування 50→100
- При ~50: коротка партнерська угода на 1–2 сторінки + реєстр внесків у таблиці. Без важких корпоративних договорів.
- При ~100: формальний shareholders' agreement, vesting-графіки, оцінка компанії; але логіка реєстру внесків лишається.

## Вихід
Заповнений шаблон часток/фінансування + рядок у партнерську угоду + запис у reєстр внесків.
