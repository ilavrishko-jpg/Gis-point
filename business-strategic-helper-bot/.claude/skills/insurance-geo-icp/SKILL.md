Зона: **Стратегія** (Core Customer, 7 рівнів). Мета — відрізнити страховиків, у яких локація входить
у **собівартість ризику**, від тих, кому гео потрібне лише для маркетингу.

## 1. Коли застосовувати
- Формуємо або переглядаємо Core Customer для страхової вертикалі.
- Треба зібрати список компаній під аутріч і відсіяти нецільові.
- Питання «чи варто витрачати час на цю страхову».
- Готуємо offer/меседж під конкретний сегмент страхування.

## 2. Алгоритм
1. **Віднеси до tier** за таблицею сегментів (нижче). Tier C — не робимо ядром.
2. **Прогони 4 шари сигналів** (структурні → документальні → вакансії/тех-стек → тригери).
3. **Порахуй скоринг** за карткою. ≥22 — Tier A, 14–21 — Tier B, <14 — відмова.
4. **Визнач бюджетотримача** (роль, не компанію) і біль під його KPI.
5. **Постав 3 верифікаційні питання** на першому дзвінку.
6. **Зведи до рядка ОСП**: Core Customer + KPI «кваліфіковані A-акаунти на квартал».

## 3. Сегменти

### Tier A — гео вшите в андеррайтинг (постійний бюджет)
| Сегмент | Навіщо гео | Бюджетотримач |
|---|---|---|
| Property P&C з NatCat-експозицією | геокодування, hazard-шари, дах/рослинність, контроль акумуляцій | CUO, Head of Exposure Management |
| Перестраховики, ретро, перестрахові брокери | cat-моделі, портфельні акумуляції, Oasis LMF | Cat Modelling / Analytics |
| Агро та індексне страхування | NDVI, засуха, моніторинг полів, збиток без виїзду | Agro product owner |
| Параметричні MGA / insurtech | продукт = гео-тригер (опади, вітер, рівень води) | Product / Data lead |
| Lloyd's синдикати й MGA | обовʼязкова звітність за сценаріями експозиції | Exposure Manager |
| Marine/cargo, energy/offshore, construction (CAR/EAR) | маршрути, порти, зони воєнного ризику, майданчики | профільний андеррайтер |

### Tier B — гео проєктно
Claims-департаменти майнових страховиків (післяподійна оцінка, change detection, тріаж FNOL —
найшвидший вхід) · мотор/телематика · title/кадастр · travel/health.

### Tier C — гео для дистрибуції
Мережа відділень, геомаркетинг, тарифні зони за індексом. Короткі проєкти, не будує повторюваного доходу.

### Дискваліфікатори
Чисте life/health · 100% мотор без телематики · GWP < €50 млн без дата-команди ·
аналітика повністю віддана перестраховому брокеру (покупець тоді — брокер).

## 4. Чотири шари сигналів
1. **Структурні** (реєстри, 5 хв): лінії бізнесу (property/agro/marine/engineering), NACE 65.12 / 65.20,
   частка майна в портфелі >20–25%, NatCat-регіони. Джерела: реєстр EIOPA, FCA/BaFin, перелік синдикатів
   і managing agents Lloyd's, AM Best; в Україні — реєстр НБУ, перелік «значимих страховиків», рейтинги Forinsurer.
2. **Документальні**: у SFCR/ORSA/річному звіті слова `catastrophe model`, `geographic concentration`,
   `accumulation`, `flood zone`, `RMS`, `Verisk`. Плюс cat bonds / ILS (Artemis), CSRD/ESRS E1 та TCFD
   (фізичні ризики по локаціях), регуляторний тиск EIOPA (рекалібрація NatCat-зарядів Solvency II),
   акредитація в держпрограмах агрострахування.
3. **Вакансії й тех-стек** (найсильніший сигнал наміру): титули `Exposure Manager`, `Catastrophe Modeller`,
   `Geospatial Data Scientist`, `Remote Sensing Analyst`, `GIS Analyst`, `Location Intelligence`.
   Вендори у вакансіях/кейсах: Esri ArcGIS, QGIS/PostGIS, Moody's RMS, Verisk, Oasis LMF, Insurity SpatialKey,
   CoreLogic/Cotality, JBA/Fathom, Nearmap/EagleView/Ecopia, ICEYE.
   - вендор є, команди немає → продаємо дані/шари й інтеграцію;
   - є і команда, і вендор → продаємо власний гео-хаб (незалежність від per-request тарифів);
   - немає нічого, але є NatCat-портфель → продаємо очищення й геокодування бази експозиції.
   Спільноти: Esri Insurance Summit / GeoConX, Oasis conference, ISCM, Understanding Risk, InsurTech NY.
4. **Тригерні події**: велика подія в їхньому регіоні · зміна регуляції · запуск параметричного продукту ·
   вихід у новий регіон · поява ролі exposure management · зміна CUO/CRO/CDO · погіршення combined ratio
   по майну · нова емісія cat bond · M&A.

## 5. Шаблон: скоринг-картка
| Критерій | Вага | 0 / 1 / 2 |
|---|---|---|
| Частка property/agro/marine у портфелі | ×3 | |
| NatCat-експозиція в регіонах присутності | ×3 | |
| Гео-ролі у штаті (вакансії/LinkedIn) | ×2 | |
| Згадки cat-моделей/гео у звітності | ×2 | |
| Власна дата-команда й хмарний стек | ×2 | |
| Тригерна подія за останні 6 міс. | ×2 | |
| GWP / здатність платити | ×1 | |

**≥22 — Tier A** (персональний аутріч) · 14–21 — Tier B (нурт + контент) · <14 — не працюємо.

**Три питання для верифікації на дзвінку:**
1. Хто відповідає за акумуляції і в якій системі зараз живе база локацій?
2. Які hazard-дані купуєте зовні і що не влаштовує — покриття, роздільність чи частота оновлення?
3. Скільки часу від події до оцінки збитку по портфелю?

## 6. Калібрування 50→100
- **Зараз (~50):** один список Tier A на 60–80 компаній у 2 країнах, скоринг вручну в таблиці,
  аутріч веде партнер/CEO + 1 аналітик. Без CRM-регламентів і без окремої ролі.
- **При ~100:** окрема vertical-команда під страхування, скоринг автоматизований (Clay / Sales Navigator),
  партнерство з MGA або cat-модельним вендором як канал продажу.

## 7. Вихід
- Список компаній із tier, балом і бюджетотримачем (роль + імʼя).
- 1 абзац Core Customer для ОСП.
- Тригер і меседж під кожен A-акаунт.
