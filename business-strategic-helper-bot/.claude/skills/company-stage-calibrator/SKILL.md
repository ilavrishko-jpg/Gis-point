# Company Stage Calibrator (50→100)

## Коли застосовувати
Майже завжди перед фінальною рекомендацією. Особливо коли йдеться про структуру,
процеси, найм, погодження, інструменти чи «давайте впровадимо ...».

## Стадія компанії 50→100 — що це означає
Це перехідна зона між «фірмою» і «компанією»: координація «в чаті та на людях»
перестає масштабуватись, але важкі корпоративні системи ще шкідливі. За Харнішем
це момент, коли потрібні **Rockefeller Habits** — мінімальні дисципліни, що тримають
зростання без бюрократії.

## Алгоритм калібрування
1. **Визнач, що болить уже зараз.** Додавай систему лише там, де її відсутність уже
   коштує грошей / часу / якості / людей. Немає болю — не додавай.
2. **Постав «тест 100 людей».** Чи витримає рішення подвоєння штату без переписування?
   Якщо ні — закладай масштабовану версію вже зараз (але в мінімальному обсязі).
3. **Обери рівень формалізації за таблицею нижче.**
4. **Дай два горизонти** у відповіді: (а) зараз ~50; (б) що додати ближче до ~100.
5. **Прогони через тест на бюрократію** (див. `lean-process-writer`).

## Орієнтири рівня формалізації
| Сфера | При ~50 (зараз) | Готувати до ~100 |
|---|---|---|
| Структура | Accountability Chart на 1 сторінку, ролі за функціями | Чіткі керівники функцій, 2-й рівень менеджменту |
| Процеси | 5–10 ключових SOP, решта — принципи | SOP для всього, що повторюється >5 разів/міс |
| Рішення | Власник вирішує сам, інформує | Зони повноважень + ескалація за винятком |
| Комунікація | Щоденний хадл по командах + тижневий по топах | Каскад: команда → відділ → компанія |
| Метрики | 1 головне число компанії + по 1 на команду | KPI-дашборд по функціях |
| Найм | Скоркарта ролі + 2 інтерв'ю | Структурований pipeline, A-гравці, онбординг-трек |

## Антипатерни (червоні прапорці для 50→100)
- Комітети та робочі групи для рутинних рішень.
- Багаторівневі погодження (>1 погодження на типову дію).
- Політики «на всі випадки» замість принципів.
- Копіювання процесів Enterprise/корпорацій 500+.
- Жорсткі посадові інструкції замість ролей за результатом.

## Формат виходу
Коротко: **Рекомендація → Зараз (~50): ... → Ближче до 100: ... → Що НЕ робимо зараз: ...**
