# Паркінг ідей

Місце, куди власник «паркує» стратегічні ідеї, щоб вони не губились до квартального планування.
Ідея тут — це **не рішення і не пріоритет**. Вона стає пріоритетом лише через `priorities-quarterly-theme`
(Топ-5 кварталу) і змінює рядок ОСП через `one-page-strategic-plan`.

## Правила (анти-бюрократія)
- 1 ідея = 1 файл `YYYY-MM-DD-коротка-назва.md`, максимум 1 сторінка.
- Обов'язково: оригінальний запис автора, суть одним реченням, який рядок ОСП змінює,
  гіпотези для перевірки, найдешевший перший крок.
- Статуси: `parked` · `exploring` (є власник і перший крок) · `in-plan` (у Топ-5 кварталу) · `dropped`.
- Жодних вигаданих метрик. Числа — лише підтверджені або явно позначені як припущення.
- Переглядаємо список на кожному квартальному плануванні.
