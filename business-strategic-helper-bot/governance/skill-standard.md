# Стандарт навички (SKILL.md)

Кожна навичка бота має відповідати цьому стандарту. Перевіряє `skill-author` перед пропозицією.

## Frontmatter (обов'язково)
```yaml
---
name: kebab-case-назва        # унікальна, коротка
description: >-               # ЧІТКІ тригери «коли застосовувати» — щоб бот сам знав, коли викликати
  Що робить + у яких ситуаціях застосовувати (конкретні слова-тригери).
---
```

## Тіло (єдина структура)
1. **Коли застосовувати** — конкретні ситуації/фрази-тригери.
2. **Алгоритм / Кроки** — мінімальні, по дієслову.
3. **Шаблон** — готовий до заповнення (де доречно).
4. **Калібрування 50→100** — для бізнес-навичок обов'язково (горизонт «зараз» і «при 100»).
5. **Вихід** — як виглядає результат.

## Критерії якості (чек-лист)
- [ ] Одна навичка = одна зона відповідальності (не змішує теми).
- [ ] Description дає однозначний тригер виклику.
- [ ] Вміщається стисло; проходить тест на бюрократію (`lean-process-writer`).
- [ ] Прив'язана до Scaling Up, де доречно (4 зони, інструменти Харніша).
- [ ] Не дублює наявну навичку (звірено з `registry.md`).
- [ ] Має блок калібрування 50→100 (для бізнес-навичок).

## Іменування
- Навичка: `kebab-case`, по суті дії (`cash-acceleration`, не `finance-stuff`).
- Папка = name; файл завжди `SKILL.md`.
