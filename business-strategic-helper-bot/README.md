# Business Strategic Helper Bot 🤖

Самовдоскональний стратегічний бот GIS-Point на базі методології **Verne Harnish «Scaling Up»**
(4 зони рішень: Люди · Стратегія · Виконання · Гроші). Компанія ~50 людей, ціль — 100.

Це GitHub-версія проєкту «Business strategic helper» з claude.ai: ті самі навички + механізм,
яким бот сам дописує навички й вирощує мережу агентів під кожен напрямок.

## Що вміє
- Дає стратегічні рекомендації за 4 зонами Scaling Up.
- **Калібрує під розмір компанії 50→100** — кожна порада з горизонтом «зараз» і «при 100».
- **Прискорює, а не бюрократизує** — кожен документ/процес проходить тест на бюрократію.
- **Самонавчається:** після задач фіксує прогалини й, коли вони повторюються, пропонує нову навичку.
- **Вирощує мережу агентів:** коли напрямок переростає навичку, пропонує окремого агента.
- Усі зміни — через цикл «пропозиція → рев'ю → злиття» з 1 підтвердженням власника.

## Структура
```
business-strategic-helper-bot/

├── .claude/
│   ├── settings.json
│   ├── skills/                # 8 бізнес-навичок + skill-author + agent-architect
│   └── agents/                # strategy / people / execution / cash-agent
├── governance/                # цикл навчання, стандарти, рубрики, реєстр, беклог
└── .github/workflows/bot.yml  # інтерактивний бот на GitHub (потрібен секрет ANTHROPIC_API_KEY)
```

## Як користуватися
**Локально (Claude Code):** відкрий теку `business-strategic-helper-bot/` — навички й агенти підхопляться автоматично.

**На GitHub (інтерактивно):**
1. Додай секрет `ANTHROPIC_API_KEY` (Settings → Secrets and variables → Actions).
2. Створи Issue або напиши коментар зі згадкою `@claude` і своїм запитом.
3. Бот відповість, спираючись на навички/агентів цього репо, і за потреби подасть PR із новою навичкою/агентом.

## Як бот «навчається»
Памʼять — це сам репозиторій. Деталі циклу: `governance/self-improvement-loop.md`.
Реєстр усіх навичок і агентів: `governance/registry.md`. Що додано й навіщо: `CHANGELOG.md`.

## Межі (чесно)
Бот не переписує себе автономно. «Навчання» реалізоване як пропозиції змін (PR) з одним
підтвердженням власника — це навмисний легкий гейт заради надійності бізнес-системи й у дусі
принципу «без зайвої бюрократії». Нові агенти/навички додаються лише за доказами повторюваності,
а не «про запас».
